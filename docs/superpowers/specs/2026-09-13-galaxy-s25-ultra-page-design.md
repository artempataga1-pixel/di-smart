# Флагманская страница Samsung Galaxy S25 Ultra

Дата: 2026-09-13

## Контекст

Параллельно с этой задачей другой агент (Codex) строит бесповедную
кинематографичную страницу `/iphone-18-pro` (hero-видео, sticky-навигация по
разделам, 17 AI-изображений, интерактивный 3D-вьюер телефона на Three.js,
Apple-style секции — дизайн/камера/батарея/AI-ассистент, аксессуары, сравнение
Pro/Pro Max). Страница не завязана на БД, CTA ведут на `/contacts`, интеграция
со стором — через общий `ShopChrome` (хедер/футер бесплатно) + отдельный пункт
навигации + запись в sitemap + промо-блок на главной.

Задача: аналогичная по уровню амбиций страница для **Samsung Galaxy S25
Ultra**, но не клон, а своя история. В БД товар `galaxy-s25-ultra` уже
существует как `isFlagship: true` с реальными ценами/вариантами
памяти/цветами (Чёрный, Титан, Синий) и рендерится сегодня через унифицированный
шаблон `/product/[slug]` — в отличие от iPhone 18 Pro, у него уже есть
работающая покупка/корзина.

**Важное ограничение параллельной работы**: Codex сейчас правит (не
закоммичено) `src/app/iphone-18-pro/**`, `src/components/home/IPhonePromo.tsx`,
`docs/iphone-18-pro/**`, `public/media/iphone-18-pro/**`, а также некоторые
общие файлы (`nav.ts`, `Header.tsx`, `page.tsx`, `sitemap.ts`). Работаем в той
же рабочей копии (без отдельного git worktree — пользователь подтвердил, что
это ок, коммитим по завершении обеих задач). Правило: **не трогать файлы,
принадлежащие iPhone-странице**; в общих файлах — только точечные, легко
мержащиеся добавления (новая запись в массиве/список), без рефакторинга.

## Принятые решения (из брейнсторминга)

1. **Модель**: Samsung Galaxy S25 Ultra.
2. **Уровень амбиций**: полный паритет с iPhone-страницей — hero-видео,
   интерактивный 3D-вьюер, AI-сгенерированная фотография.
3. **Главный нарратив**: не один акцент, а три фичи распределены по разделам
   равноценно — S Pen (творчество/продуктивность), камера + Galaxy AI
   (технологическое превосходство), титановый корпус (премиальный дизайн,
   инженерия). Хедлайн ведёт с дизайна (аналог входа у iPhone), дальше — S Pen,
   камера/AI, остальное вглубь.
4. **3D-модель**: у Apple был готовый USDZ-файл, у нас — нет официального
   ассета. Решение: на этапе реализации подобрать лицензионную 3D-модель
   Galaxy S25 Ultra (Sketchfab/CGTrader, проверить лицензию на коммерческое
   использование) или сгенерировать через image-to-3D пайплайн. Обязателен
   фолбэк на 360°-фотоспин (серия AI-изображений под разными углами), если
   подходящую модель не найдём/она не проходит по качеству или лицензии.
5. **Hero-видео**: пользователь пришлёт готовый видеофайл позже. Верстаем
   `HeroFilm`-компонент так, чтобы видео подключалось заменой одного файла
   (плюс постеры первого/последнего кадра) — сейчас работаем с
   заглушкой-постером (статичный кадр/рендер телефона), тем же поведением
   (автоплей раз, pause/replay, `prefers-reduced-motion` → постер,
   graceful fallback при ошибке).
6. **CTA покупки**: ведут на реальную покупку — `/product/galaxy-s25-ultra`
   (там уже есть выбор памяти/цвета и рабочая корзина). Это осознанное отличие
   от iPhone-страницы (там CTA → `/contacts`, т.к. товара в БД нет).
7. **Подход к переиспользованию кода**: независимая реализация (вариант A).
   Ничего из `iphone-18-pro/**` не импортируется и не рефакторится сейчас —
   слишком велик риск конфликта с незакоммиченной параллельной работой.
   Вынесение общих примитивов (`HeroFilm`, sticky-нав, 3D-вьюер) в
   `src/components/flagship/` — возможный будущий рефактор **после** того,
   как обе страницы закоммичены, отдельной задачей.

```

                                     рендерит <GalaxyHero/>, без обращений к БД
  galaxy-hero.tsx                 — "use client", всё тело страницы:
                                     sticky in-page нав + все секции +
                                     IntersectionObserver для reveal-анимации
                                     и активного пункта навигации
  galaxy-content.ts               — chapters (нав), highlights (рейл),
                                     finishes (3 цвета с hex, синхронно с БД:
                                     Чёрный/Титан/Синий), cameraDetails,
                                     accessories, lineupTiers (S25/S25+/Ultra),
                                     questions (FAQ)
  galaxy-media.ts                 — id → {src, alt, fit, position}, пути под
                                     /media/galaxy-s25-ultra/...
  galaxy-hero.module.css          — секции, CSS custom props, clamp()-типографика,
                                     скруглённые медиа-фреймы, sticky/blur-нав,

                                     breakpoints 1000/760/360px,
                                     prefers-reduced-motion overrides
  hero-film.tsx + .module.css     — свой видео-компонент (poster fallback,

  phone-viewer.tsx + .module.css  — обёртка 3D-вьюера: lazy-mount по
                                     IntersectionObserver, постер до готовности,

  s-pen-showcase.tsx              — секция S Pen: свой компонент, аналога в
```

## Контент: порядок секций

1. **Hero** — видео (заглушка-постер до присылки файла), заголовок, CTA
   «Купить» → `/product/galaxy-s25-ultra`
2. **Highlights-рейл** — горизонтальный скролл с ключевыми фичами (S Pen,
   200MP, титан, Galaxy AI, батарея, дисплей)
3. **Дизайн** — титановый корпус, 3 реальных цвета (Чёрный/Титан/Синий) с
   переключателем, интерактивный 3D-вьюер (или 360°-фотоспин)
4. **S Pen** — творчество/продуктивность, галерея сценариев использования
5. **Камера + Galaxy AI** — 200MP, зум, AI-редактирование фото
6. **Производительность** — чип, игровой сценарий
7. **Батарея/зарядка**
8. **Galaxy AI / One UI experience** — демо-блок (аналог Siri-раздела у
   iPhone, но про Circle to Search / Generative Edit)
9. **Аксессуары** — реальные товары из БД (S Pen Pro, чехол `galaxy-s25-case`,
   зарядки `samsung-25w-charger`/`samsung-45w-charger`) со ссылками на их
   `/product/[slug]`
10. **Сравнение линейки** — S25 / S25+ / S25 Ultra, переключатель со ссылками
    на реальные товарные страницы (аналог Pro/Pro Max picker у iPhone)
11. **FAQ**
12. **Футноут** — честная пометка, что фото/видео/3D — AI-реконструкции или
    иллюстративный материал, не официальные материалы Samsung
13. **Финальный CTA-блок** → `/product/galaxy-s25-ultra`

## Арт-дирекшн медиа

- Фотореалистичный стиль без «CGI-глянца» (как в iPhone-серии): реальная
  оптика (35–100mm, f/4–f/8), 3:2 landscape, без наложенного текста.
- **Холодная палитра** — титан/серебро, глубокий синий, чёрный — в
  противовес тёплой бордовой iPhone-палитре.
- **Другая локационная тема** — урбанистика/ночной город/неон вместо тёплой
  природы/пляжа у iPhone, чтобы страница не читалась клоном по настроению.
- Каждое изображение — с промптом, сохранённым в `docs/galaxy-s25-ultra/`
  (по аналогии с `natural-image-prompts.json` у iPhone), для воспроизводимости
  и ревью.
- 3D-ассет: перед использованием стороннего файла — проверить лицензию на
  коммерческое использование на сайте; при отсутствии подходящего варианта —
  360°-фотоспин, без блокировки остальной работы.

без рефакторинга структуры файла, чтобы минимизировать конфликты при
одновременной работе с Codex.

## Тестирование/верификация

- Запуск `next dev`, визуальная проверка в браузере: desktop и мобильный
  вьюпорт, тёмная тема (`.site-theme` — глобальная, применяется автоматически).
- Проверка `prefers-reduced-motion` (видео/анимации должны показывать
  статичный постер/без reveal-анимации).
- Проверка, что `next build`/`sitemap.ts` (он `force-dynamic`, читает БД)
  не ломается новой статической записью.
- Проверка, что e2e-тесты Playwright не задеты (они не покрывают эту
  страницу, но убедиться, что `iphone-17-pro-max` и общие сценарии
  `price-recalculation`/`order-flow` не пострадали от правок в `nav.ts`/
  `Header.tsx`/`page.tsx`).
- Ручная проверка: CTA «Купить» реально доводит до `/product/galaxy-s25-ultra`
  с корректным товаром, выбор цвета в 3D-вьюере не обязан быть синхронизирован
  с реальным выбором варианта на странице покупки (это разные страницы) —
  но цвета в сторителлинге должны совпадать с реальными цветами из БД.
