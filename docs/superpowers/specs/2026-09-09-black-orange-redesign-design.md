# Редизайн: чёрно-оранжевая айдентика, главная страница, карточка товара

Дата: 2026-09-09

## Контекст

Референс «фон» (Aarounda color/typography board) задаёт палитру и градиент, который
должен стать основной айдентикой сайта: чёрный фон + тёплый оранжево-золотой
градиентный блик. Палитра из референса:

- `#FFB000` — амбер (акцент/иконки/ховеры)
- `#FFD985` — светлый персик/крем (мягкий блик градиента)
- `#FF7700` — оранжевый (основной CTA/акцент)
- `#060605` — почти чёрный (фон)
- `#FFFFFF` — белый (текст/контраст)

Важная находка при аудите кода: этот градиент **уже реализован**, но заперт в
`FlagshipGradientBackground.tsx` и применяется только на тёмной теме карточки
iPhone 17 Pro (`.flagship-theme--dark` в `flagship.css`). Остальной сайт
(`tokens.css`) живёт на светлой бело-голубой палитре. Задача — вынести эту
палитру на уровень всего сайта и убрать дублирование.

Референсы для главной страницы: Apple-style hero (полноэкранное фото товара,
минимум текста), Nike-style bento-грид (группировка блоков без листинга
товаров), Aarounda-style «01/02/03» сторителлинг тремя картинками.

Референсы для карточки товара: Beats Studio landing и Velyr — крупные фото на
periферии, крупный шрифт, кнопка покупки рядом с «показать больше», скролл
раскрывает варианты/характеристики.

## Технические ограничения

- У большинства товаров в базе **1 фото** (сидируется через `mainImage` в
  `prisma/seed.ts`). Мультифото (2-3+) есть только у двух флагманов, залитых
  вручную через админку. → карточка товара обязана адаптироваться под
  количество фото, а не требовать 3 фото жёстко.
- Админ-панель (`/admin`) в редизайн не входит — остаётся как есть.
- Структура/вёрстка header, footer, каталога не меняется — только цвета.

## Этап 1 — Базовая палитра сайта

### `src/app/styles/tokens.css`

Полностью переписывается на тёмную схему (сейчас в этом виде существует
только как scoped override в `.flagship-theme--dark`):

```
--color-bg: #060605
--color-surface: #15130f
--color-surface-soft: #201c16
--color-line: rgba(255, 255, 255, 0.14)
--color-text: #ffffff
--color-muted: rgba(255, 255, 255, 0.64)
--color-accent: #ff7700
--color-accent-ink: #ffb000
--color-accent-dark: #e86800
--color-accent-soft: rgba(255, 119, 0, 0.16)
--color-accent-glow: rgba(255, 119, 0, 0.45)
--color-cream: #ffd985      /* новый токен — третий блик градиента */
--color-ink / --color-on-ink — пересмотреть под тёмный фон (футер и так был тёмным, теперь совпадает с общим фоном, упростить до алиасов --color-bg/--color-surface)
--color-success / --color-warning — оставить текущие значения (#7bd99b / #f2b134), они уже читаемы на тёмном
```

Радиусы и тени остаются, тени пересчитать под тёмный фон (снизить непрозрачность
белого свечения вместо тёмных теней).

### Глобальный градиентный фон

`FlagshipGradientBackground` обобщается в `GradientBackdrop` и переезжает на
уровень `layout.tsx` — рендерится один раз на весь сайт (fixed/absolute,
`pointer-events-none`, за контентом), вместо того чтобы каждая страница
монтировала свой набор blob'ов. Значения блобов (#FF7700, #FFB000, #FFD985,
позиции/blur/opacity) берутся из текущей dark-версии `FlagshipGradientBackground`.

`.flagship-theme--dark` / `.flagship-theme--light` в `flagship.css` удаляются —
эти токены становятся дефолтом сайта. `flagship.css` сокращается до
специфичных для флагман-страниц вещей (если останутся после этапа 3).

### Что перекрашивается

Header, footer, каталог (список товаров), карточки товаров в списках — только
цвета через существующие CSS-переменные, вёрстку не трогаем.

## Этап 2 — Главная страница

Текущая структура (`src/app/page.tsx`): Hero → Категории → грид из 2 флагманов
(`FlagshipProducts`, использует обычный `ProductCard`) → инфо-плашки → грид
популярных товаров → контакты. Это и есть тот самый «каталог», от которого
хочет уйти пользователь.

Новая структура — 3 секции:

### 1. Flagship Showcase (замена `MoonHero` + `FlagshipProducts`)

Новый клиентский компонент, объединяющий фото + сторителлинг + навигацию в
один блок:

- Верх: полноэкранное фото текущего флагмана, крупное имя, цена, кнопка
  «Смотреть товар» → `/product/[slug]`
- Под ним: 3 крупные картинки-истории об этом же товаре с короткими
  подписями (в духе Aarounda «01/02/03»); если у товара < 3 фото —
  используются доступные (2 или даже 1, крупнее)
- Стрелки/точки переключают весь блок между флагманами (`getFlagshipProducts`,
  сейчас 2 товара, ротация — не автоплей, ручное переключение как в текущем
  `HeroCarousel`)
- Заменяет собой `MoonHero.tsx`, `HeroCarousel.tsx`, `FlagshipProducts.tsx`

### 2. Группировка (замена `CategoryGrid` + `InfoTeasers` + `PopularProducts`)

Bento-грид 4-6 плиток: категории (из `CategoryGrid`), trade-in, доставка
(из `InfoTeasers`), и одна крупная плитка-CTA «Весь каталог →». Полный грид
товаров (`PopularProductsGrid`) с главной убирается — каталог живёт на своей
странице `/catalog`.

### 3. Контакты (`ContactTeaser`)

Остаётся как есть, только цвета из новой палитры (уже используют CSS-переменные,
изменений в разметке не требуется).

## Этап 3 — Универсальная карточка товара

`FlagshipProductPage` обобщается в единый шаблон, который использует
[product/[slug]/page.tsx](../../../src/app/product/[slug]/page.tsx) для **всех**
товаров (не только `isFlagship`) — заменяет текущую ветку
`Breadcrumbs + ProductPurchasePanel + ProductSpecsTable + RelatedProducts`.

Структура:

1. Тонкая строка хлебных крошек сверху (для навигации/SEO — в текущем
   flagship-шаблоне их нет, добавляем универсально)
2. Адаптивная фото-секция:
   - 1 фото → крупный full-bleed hero (как текущий `FlagshipHero`)
   - 2-3+ фото → галерея-периферия: главное фото крупно + 1-2 вспомогательных
     ракурса рядом/снизу (референс Beats/Velyr)
3. Крупное имя товара, цена, кнопка **«Купить»** + рядом **«Показать больше»**
   (скролл к следующему блоку/expand)
4. Раскрывающийся блок: цветовые варианты и атрибуты (логика `ProductInfo`
   переиспользуется), описание, характеристики (паттерн collapse уже есть в
   `ProductSpecsTable`, расширяется на весь блок)
5. «Смотрите также» — `RelatedProducts`, с кнопками на другие товары

`ProductGallery` и `ProductInfo` переиспользуются под капотом (логика выбора
цвета/варианта не меняется), меняется визуальная подача — full-bleed вместо
side-by-side колонок с рамками.

После этого `ProductPurchasePanel` как отдельный компонент, вероятно,
упраздняется (логика переезжает в новый шаблон), `FlagshipFeatureGrid`
(текстовые спек-карточки) либо удаляется, либо данные переезжают в общий
`ProductSpecsTable`.

## Порядок реализации

Этапами, с возможностью посмотреть каждый в браузере до перехода к следующему:

1. Палитра (`tokens.css` + глобальный `GradientBackdrop` + перекраска
   header/footer/каталога)
2. Главная страница (Flagship Showcase + группировка + контакты)
3. Универсальная карточка товара

## Вне скоупа

- Админ-панель (`/admin`) — цвета не трогаем
- Структура/вёрстка header, footer, каталога — только перекраска
- Добор дополнительных фото для товаров с 1 фото через админку — не в этой
  задаче, карточка адаптируется к тому, что есть
