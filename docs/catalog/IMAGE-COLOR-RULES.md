# Правило фотографий при выборе цвета

Для цветов одной модели используется один эталонный кадр. Разрешено менять только цвет и отделку корпуса, цвет ремешка и подпись выбранного варианта.

Нельзя менять масштаб, положение, ракурс, перспективу, форму устройства и ремешка, кадрирование, фон или циферблат. Нельзя генерировать каждый цвет как самостоятельную композицию.

Перед публикацией проверять не только размеры файлов: старые несовпадающие изображения тоже имели одинаковые холсты. Сверять детали и контуры с эталоном, затем переключать все цвета в настоящей карточке на компьютере и телефоне. Размер и положение области изображения должны оставаться постоянными. Для часов переключение выполняется без наложения двух кадров.
