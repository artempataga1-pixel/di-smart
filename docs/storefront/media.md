# Медиа для светлой витрины

Главная использует товары, isFlagship, shortDescription, canonicalPath и категории из PostgreSQL. Новые модели и бренды не добавлялись. Промо не содержит отдельной копии каталога.

## Изображения

Для каждого товара можно добавить `public/products/<product-slug>/promo.webp`: этот файл получает приоритет перед изображениями из админки. Рекомендуемый размер — 1800–2400 px, прозрачный или очень светлый фон, устройство крупно и целиком. Минимум для текущего слота — 900 × 700 px. Файлы меньшего размера не растягиваются. При отсутствии подходящего изображения показано «Фотография скоро появится».

Для флагманов из текущего seed нужны:

- `public/products/iphone-17-pro/promo.webp`
- `public/products/iphone-18-pro/promo.webp` — сейчас используется существующая фотография на тёмном фоне; для полного соответствия референсу нужен светлый рендер.
- `public/products/galaxy-s25-ultra/promo.webp`

Категории используют фото своих товаров. Для iPad, MacBook, Apple Watch, AirPods и остальных семейств нужно загрузить хотя бы один качественный рендер конкретной модели из соответствующей категории. Нельзя подставлять фотографию другого устройства ради заполнения блока.

## Категории

12 изображений пользователя подключены из `public/media/storefront/categories/<category-slug>.webp`. При совпадении имени с slug категории эта фотография имеет приоритет над фото товара. Исходники в `masters/` не загружаются браузером.

## Видео

Подключён предоставленный пользователем `hero-di-smart.MP4`:

- `public/media/storefront/hero.mp4` — веб-версия 1920 × 824, H.264, faststart, без звуковой дорожки; 16,2 с, около 5,9 МБ вместо 40 МБ.
- `public/media/storefront/poster.webp` — первый кадр ролика.

Видео воспроизводится автоматически без звука один раз и остаётся на последнем кадре. Кнопка воспроизведения позволяет запустить его повторно. Панорамные пропорции сохранены на всех экранах, без обрезки логотипа. Под видео — кнопка «Смотреть каталог».

При reduced motion видео не загружается автоматически. При ошибке загрузки остаются постер и ссылка в каталог. Есть кнопка паузы; при уходе блока за экран воспроизведение приостанавливается.

## Локальная проверка

Рабочая база не была настроена. Проверки выполнены на временной PostgreSQL (порт 55432), с миграциями и существующим seed. Скриншоты и результаты браузерной проверки — `output/storefront/`. Эти данные не являются выгрузкой рабочего каталога.
